Password Generator

Objective

The objective of this project is to create a Password Generator using Python that generates strong and random passwords for users.

Steps Performed

1. Accepted the desired password length from the user.
2. Used random characters, digits, and symbols.
3. Generated a secure password.
4. Displayed the generated password.

Tools Used

- Python
- VS Code
- GitHub

Outcome

The project successfully generates strong and random passwords that can be used for secure accounts and applications.

How to Run

1. Open the project in Python.
2. Run the password generator file.
3. Enter the required password length.
4. View the generated password.
